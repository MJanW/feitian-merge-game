# 合成飞天

个人照片小游戏，顶部标签切换一周目「合成飞天」、二周目「带队飞天」、三周目「跳跃飞天」与四周目「守卫飞天」。切换会暂停原模式，返回可继续。

界面采用纸白、深绿与朱橙配色，使用宋体标题、等宽分数和编号标签。手机将分数与操作收紧，为画布保留空间；四个模式、排行榜和结算页使用统一的细线与小圆角样式，不依赖外部字体服务。

- 12 个等级（-1 → 0 → … → 10）：大水瓶是最初级，透明人物素材依次升级。
- 两个水瓶合成原 0 号人物，合成原 10 号时播放《飞天》。
- 新 9 号照片已更新为透明人物抠图；最近一轮相对前版：−1 号放大 15%、1 号放大 20%、2 与 3 号各放大 10%、4 号放大 5%，同步调整碰撞。此前 0、4、7 号的调整已计入基准。
- 10 号在上一版基础上放大 15%，同步调整碰撞范围。
- 两个 10 号融合后爆炸消除，奖励 300 分和一枚复活币。
- 手机画布按可用高度等比适配，横屏操作区并排显示；弹窗支持安全区、滚动与软键盘可视区域。
- 合成、跳跃和守卫各有独立的 Supabase 共享历史 Top20，共用浏览器身份和昵称。合成与跳跃记录最高分，守卫记录已结束对局的最高到达波数，每位玩家在每张榜仅保留最佳纪录。
- 守卫点击顶部「波次 · 榜」或结算页「波数排行榜」进入；结算自动上传，断网保留待补传记录。同波数先到优先，旧积分不会转换成波数。
- 跳跃模式点击「最高分 · 排行榜」或结算页的「排行榜」进入；结算自动上传，网络失败可重试，之前的 v2 本机最高分可以确认后补传。
- 已结算成绩先保存在本浏览器待上传队列，超时可重试，重开或刷新后可补传；旧版本机最高分可在排行榜内确认后补传。
- 自动匿名身份，无需玩家登录；换设备、清除数据或更换网站域名会产生新身份。
- 二周目拖动水瓶领队，把散落的朋友带进出口；队伍弹性跟随，撞到障碍会掉队，可以返回救援。三关家具数量为 6、10、14 件，巡逻鹅为 1、2、3 只，时限为 45、50、60 秒，第三关还有旋转风车；沙发、桌子和玩偶均由照片抠成透明素材，并可重复出现。
- 拾取蓝色玩偶后全队获得 6 秒抗撞保护，仍需绕过家具、避免队伍拉散；长鹅会沿路线往返，碰撞可使伙伴掉队。
- 救援模式每关有倒计时，首次移动才开始；暂停、重开、选关及本机关卡纪录可用。限时挑战版使用独立的本机最高分，旧版记录保留，救援成绩不写入合成共享榜。
- 三周目按住画布、蓄力按钮或空格键，松开后朝下一座平台跳跃。普通落台 +1，连续中心落台依次 +2、+4、+6、+8、+10…，单次最高 +32；普通落台或落回原台重置连击，落空结束本局，平台持续生成。
- 跳台有纸箱、彩色魔方、唱片、草地台、书本、便利店、鼓、六角石台和井盖 9 类模型，大小、厚度和间距交错变化。落点判定跟随圆形、方形或六角形顶面，近跳和远跳、大台和小台持续混合出现。
- 井盖、魔方、便利店、唱片台落稳停留 2 秒，各额外 +5、+10、+15、+30 分，每座只领一次；暂停冻结等待，蓄力会重新计时。
- 跳跃加入独立蓄力、起跳、落地、中心连击、平台奖励、进化及落空音效，随共用音效开关同步；本机最高分继续保留。
- 跳跃每累计 50 分进化一次：图 -1 → 0 → … → 10，共 12 种形态；550 分到图 10，600 分回到图 -1 进入第 2 轮，持续循环，没有关卡终点或人为分数上限。
- 跳距按画面投影距离计算，相同画面距离需要的蓄力时长不因方向改变。蓄力灵敏度为最初调整前的 4/5，比此前 2/3 版本提高 20%；满蓄力需 1.5 秒，最大跳距保持不变。每次开新局都会重新随机起点左右位置及后续平台的方向、距离、大小与造型，第一跳不再固定；平台仍经过可达性和画面遮挡检查。预计稳定落台前最后 120 毫秒可提前按住，落地后才从零蓄力；提前松手则取消。
- 所有形态共用可见脚底圆圈：与真实台面重叠面积至少 50% 才站稳；部分搭边但不足 50% 时，先短暂停住，再绕接触处倾倒滑落。完全落空直接坠落，失稳不加分；照片大小及透明区域不影响判定。
- 蓄力时角色高度随按住时长线性压缩：半蓄力压缩 25%，满蓄力压缩 50%，同时适度横向展开。连续起跳时保留回弹的初始姿态，再快速衔接蓄力形变；松手保留当下形状，由阻尼弹簧完成起跳拉伸与落地回弹。下落带少量衰减前冲、逐渐倾斜和后段淡出，前方台体会遮挡下落角色。切回页面后点击一次“继续”即可恢复。
- 腾空时按跳跃方向绕人物中心翻转一圈，落地前恢复直立；蓄力压缩和落地回弹保留，暂停会冻结动画，系统启用减少动态效果时不翻转。翻转不改变跳距、碰撞或计分。
- 跳跃模式手机版画布使用可用宽度与剩余高度，角色最大绘制框为 34.56×39.36，较此前 43.2×49.2 再缩小 20%；脚底支撑圆圈保持原有大小。去除进化与蓄力进度条，蓄力仍有角色压缩反馈。新规则的本机最高分独立保存，旧记录保留且不混算；暂停和切换模式会取消未完成蓄力，空中跳跃则冻结，回来后继续。四个模式共用音效开关。

第四周目采用双通道旋刃塔防，真实酒瓶为敌人，靠右击蛋招募同伴。上下两区各4×5，共40个阵位完整显示；拖动可移动、换位或合成：同级同元素优先合成，保留接收方技能，失败只消耗材料；无法合成时交换位置且保留等级、技能与冷却。普通→黄金优先投喂，黄金→普通交换。普通合成仅按角色等级计算：Lv1始终100%，每级减少3个百分点，最低55%，波次不影响。冰、火、雷、土、草拥有进阶属性、技能及15种后期强化，不同元素攻击同一目标触发反应。第21波起，Lv10以上合法合成有独立3%概率觉醒黄金战士，每局一次；任意普通守卫可投喂，每次升阶需累计30、60、120、240、480…级材料；黄金1阶击蛋召出Lv10普通守卫，每升1阶召出等级加1；每名产物等概率随机获得冰/火/雷/土/草之一，并补齐已解锁同系路径，满场待命保留抽到的路线。黄金原基础攻击30逐阶乘2（60、120、240…），第3/5/7…阶选择飞剑、领域或共鸣天赋，黄金与五元素均可反应。垃圾筐可清理普通守卫。最高到达波数独立共享排名，游戏积分保留在本机。

这是公开静态发布目录。所有游戏资源随站点提供，合成、跳跃和守卫排行榜连接 Supabase。
客户端配置只包含公开 publishable key；数据库访问由服务器权限控制。

网站通过 GitHub Pages 从 `main` 分支根目录发布。

计分参考经典版：原始实玩规则记录（[中心奖励最高 32 分](https://www.cnblogs.com/dotnet-org-cn/p/8149693.html)；[特殊平台停留 2 秒与 +5/+10/+15/+30](https://www.jiemian.com/article/1851687.html)）。音效为自行用 Web Audio 合成的短音，不使用原版音频素材。

跳跃平台反馈（blockpress1）：蓄力时平台厚度最大压缩10%，小于人物50%；台底与阴影固定、脚底随台面下移，松手和落地带轻微回弹。路线改为两条世界坐标直角轴，随机直行1–3跳或转90°，镜头水平跟随；平台大小、造型和间距仍随机，保留4/5灵敏度、原计分、每50分进化与共享榜。


## 第五周目 · 飞天花园 · 经典白天 Demo

在顶部「05 飞天花园」进入。玩法向经典一代白天草坪校准，场景、敌人造型及角色装饰由本项目绘制；前三关保留中间一行→三行的开场、射手→产阳光→爆破的开放顺序，具体出怪秒表为演示脚本。第四项「自由演练」可直接选择，开放五行九列、六张角色卡和铲除工具。

新增完整准备流程：庭院地图选关 → 种子盒选择本局伙伴 → 2.4 秒可跳过开场 → 布阵战斗。出战阵容需有持续射手，开放日光伙伴的关卡也必须携带日光伙伴；未选卡片不能在战斗中种植。开场冻结资源和敌人时间，切出后需明确继续。地图使用本机通关花朵标记。

人物增加呼吸、轻摆、射击回弹与受击压缩；僵尸增加关节步态、受击后仰、本体生命≤180时的一次无血断臂、倒地与尘土动画。护甲判定、伤害、阳光及原关卡数值保持，四轮小推车保留。最后一次死亡动画可播完再显示结算；仅推进展示时间，不继续战斗。


- 阳光每次25；产阳光首轮约7秒，之后约24秒；普通种子卡7.5秒冷却、盾卫30秒、爆破50秒。天降阳光真实落下，落地后7.5秒消失。
- 普通植物300生命、盾卫4000；射手每发20、冰弹同时让移动和啃咬减半、双发间隔150毫秒、爆破引燃1.2秒并造成3×3范围1800伤害。
- 普通、旗帜、路障、铁桶、撑杆五类敌人；护甲先破损，本体失去头部后不再啃咬，身体短暂移动、挡弹；撑杆越过第一株植物后弃杆变慢。每条开放小路有一次清扫车。
- 教学未完成时只开放指定卡，防止种满错误角色卡住。切模式、失焦、后台会暂停；回来需点击继续。铲除不返还阳光。通关记录使用新的本机键，不混用旧Demo记录，也不新增联网榜。
- 根据用户文件名，图0/2/4/6对应产阳光/射手/盾卫/冰霜，图10用于小推车；新77双人合照用于双发，新81用于爆破。其余新照片已抠好；高坚果、玉米投手、玉米加农炮、火炬的对应素材已登记，尚未在本Demo实现。
